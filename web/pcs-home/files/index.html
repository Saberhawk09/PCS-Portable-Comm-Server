PCS FIELD REFERENCE

Files

Local file shares for the field team. No browser file manager or Internet connection is required.

PCS-Share

Primary shared storage.

\\10.42.0.1\PCS-Share

Use the access permissions configured by your PCS administrator.

PCS-Backup

Backup storage. Administrator credentials are required.

\\10.42.0.1\PCS-Backup

Sign in as pcs-admin with the PCS administrator password. Backup jobs are managed in Admin.

Connect from Windows

  1. Connect to the PCS LAN or its Wi-Fi access point.
  2. Open File Explorer and enter the share address in its address bar.
  3. If prompted, enter the credentials provided for that share.

You may also find PCS-FILE-SHARE under Network. Use the IP address if discovery is unavailable.

Connect from Linux

  1. Connect to the PCS network.
  2. Open your file manager’s “Connect to Server” or “Other Locations” view.
  3. Enter smb://10.42.0.1/PCS-Share or smb://10.42.0.1/PCS-Backup.
  4. Enter share credentials if requested.

Share unavailable?

Check USB and file-sharing health on the Status page. Keep storage connected until an administrator has safely unmounted it.
