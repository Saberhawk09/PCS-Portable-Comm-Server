# Project Overview

PCS is a portable communications server designed to provide reliable local networking, cellular internet access, LAN file sharing, and GPS-disciplined time services for field operations.

The project is built around discrete, repairable components instead of relying on one opaque all-in-one appliance.

## Core Goals

- Reliable wired and wireless LAN
- Cellular internet for connected clients
- LAN-hosted file share
- GPS-disciplined NTP server
- Grid and emergency power support
- Rugged, simple operation
