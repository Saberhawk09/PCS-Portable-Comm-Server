## Manufacturer and service verification

The exact F10 SPG 6.00 / protocol 40.00 interface, message versions, sizes,
bitfields and scales were checked against
[UBX-23002975 R02](https://content.u-blox.com/sites/default/files/documents/u-blox-F10-SPG-6.00_InterfaceDescription_UBX-23002975.pdf).
Compatibility is software/documentary, not new hardware acceptance. In particular,
MON-SPAN uses quarter-dB amplitudes and the documented bin-127 frequency origin;
SEC-SIG version 1 is not decoded using a newer-generation layout.

The [NEO-F10N Integration Manual](https://content.u-blox.com/sites/default/files/documents/NEO-F10N_IntegrationManual_UBXDOC-963802114-12193.pdf)
explicitly warns against BeiDou B1I aiding on the B1C receiver. Both requests
and validators restrict assistance to GPS/Galileo. Autonomous runs internally;
default orbit-error thresholds are preserved. DBD/flash behavior remains
unqualified and disabled.

The current [Thingstream guide](https://support.thingstream.io/hc/en-gb/articles/20837860069788-AssistNow-Getting-Started-Guide)
and [API](https://assistnowapi.services.u-blox.com/) confirm device ZTP enrollment,
chipcode/allowedData credentials and Predictive windows 1/3/7/14 days. Predictive
is free; Live is premium or evaluation-dependent. Local conservative caps,
per-attempt reservation and explicit enable/request confirmation protect usage.
An account's exact plan and remaining evaluation quota cannot be inferred from
the public API metadata and require operator verification.

## Deployment boundary and remaining acceptance

The implementation keeps GPSD as normal UART owner and restricts maintenance
to explicitly released ownership. Passive diagnostics cannot restart GPSD or
Chrony. Boot injection is opt-in, inside the existing exclusive admission scope,
with receiver-resolved UTC and no usable fix. New downloads arriving later are
cache-only; fresh online Live injection during ordinary acquisition is not
qualified. Backup-memory loss falls back to normal acquisition rather than
injecting an untrusted clock value.

Remaining external gates: real account enrollment/entitlements and payload
interoperability; appliance resource measurements; supervised maintenance RAM
ACK/readback; receiver-specific spectrum output availability; captured RF events;
power-loss/reboot behavior with opted-in assistance; sustained physical PPS
continuity; and measured TTFF benefit. No improved PPS accuracy is claimed.
DBD backup/restore, live message-rate changes, position optimization and cold-start
time aiding remain disabled until separately qualified.

Expected/enforced overhead and rollback/failure recovery are detailed in the
[installation guide](gnss-intelligence-install.md). That guide is the installation
procedure; do not run the full PCS base installer for this candidate. The
candidate does not include or modify a recovery kit/SD image.
