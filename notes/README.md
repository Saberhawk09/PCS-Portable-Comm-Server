# Historical Project Notes

The files in this directory are dated development records. They preserve the sequence of PCS bring-up, experiments, temporary configurations, and decisions, but they are **not current setup or operating instructions**.

Terms such as “current,” “next,” “final,” or “pending” inside a dated entry describe the project only at the time that entry was written. In particular, the early Actiontec/Windstream router tests, temporary Wi-Fi uplink, temporary Samba path, original port-80 redirect, and pre-WWAN/GNSS plans have been superseded.

Use these maintained documents for the current system:

- [Root README](../README.md) — public status and quick-start entry point
- [Project Overview](../docs/project-overview.md) — current feature and hardware status
- [Network Topology](../docs/network-topology.md) — authoritative addressing and device roles
- [Full-Stack Reinstall Runbook](../docs/full-stack-reinstall.md) — recovery and rebuild procedure
- [Bill of Materials](../docs/bill-of-materials.md) — acquisition and installation status
- [Testing Checklist](../docs/testing-checklist.md) — current validation procedure
- [Changelog](../CHANGELOG.md) — released and unreleased software changes

## Files

- [Raspberry Pi Bring-Up Log](pi-bringup-log.md) — initial July 1 Pi experiment and validation record
